# Security Conference Presentations

A collection of slides from my conference talks, workshops, and technical presentations on **incident response, DFIR, threat hunting, malware, anti-forensics, Linux security, and macOS forensics**.

Most of the material is based on techniques, artefacts, and lessons learned from real-world incident response investigations.

## Topics

The presentations mainly cover:

- 🔍 **Incident Response & DFIR**
- 🥷 **Anti-Forensics**
- 🐧 **Linux Rootkits & Linux Forensics**
- 🍎 **macOS Forensics**
- 🐀 **RATs & Malware**
- 🎯 **Threat Hunting**
- 🧠 **C2 Frameworks & Adversary Tradecraft**
- 🔑 **Credentials & Authentication Artefacts**

## About

I'm **Stephan Berger ([@malmoeb](https://github.com/malmoeb))**, an incident responder and security researcher.

My research focuses heavily on techniques and artefacts that are useful during real-world investigations — particularly unusual persistence mechanisms, anti-forensics, malware tradecraft, Linux and macOS threats, and hunting opportunities that can be derived from actual incidents.

More DFIR research and field notes:

👉 [**dfir.ch**](https://dfir.ch)

## A Note About the Slides

Some talks revisit the same research topic at different conferences. Newer versions may contain updated case studies, techniques, detections, or additional research.

The slides are published primarily as a reference for the security and DFIR community.

If you find something useful, have additional artefacts to share, or want to discuss one of the techniques, feel free to reach out.
